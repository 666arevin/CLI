# Игра камень ножницы бумага.

1. Установка
Для того чтобы скачать игру себе пропишите:
```bash
git clone https://github.com/666arevin/rock_paper_scissors.git
```

2. Запуск 
1 Вариант
Для запуска игры запустите файл start_game
2 вариант 
для запуска пропишите 
python "<путь к файлу>/app/start.py"

Информация о способах навигации и взаимодействия с игрой будет указанно после запуска игры.
